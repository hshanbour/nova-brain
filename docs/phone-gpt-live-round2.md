# Phone GPT-Live Round 2 (non-PSTN prototype)

This Preview-only prototype keeps GPT-Live as the conversational presentation layer and Nova Brain as the authority. It does not replace or alter the operational chained Phone V1 route.

## Canonical timeline

Every turn uses one existing `nova_conversations` identity. User and assistant text remains in `nova_messages`; the additive `nova_conversation_events` ledger records authority decisions, intended output, delivered output, interruption, replacement, and reintegration. `nova_conversation_live_state` holds an optimistic context version, bounded rolling summary, and bounded unresolved state. Raw audio is never stored.

## Authority and output gate

The application classifies each final caller utterance as `LOCAL_CONVERSATION`, `NOVA_INFORMATION`, `NOVA_ACTION`, or `CLARIFICATION_REQUIRED` before releasing speech. Local conversation can be released and persisted exactly once. Nova-owned facts are delegated read-only to the existing agent with the same conversation ID and canonical context; speculative local output is discarded. Actions stop without execution or approval creation in this certification prototype. Spoken approval is non-authoritative.

Nova results return to the active Live session as application commentary with `delegation_id: null`, matching OpenAI's application-started session-update contract. Reconnect loads canonical messages, events, rolling summary, unresolved state, and context version from Nova storage.

## Personality

Live sessions import the shared `NOVA_COMMUNICATION_POLICY`. Phone adds only presentation guidance for concise speech, natural Jordanian/Levantine Arabic, mixed Arabic-English technical terms, turn-taking, and yielding on interruption.

## Bounded internal surface

The prototype routes under `/api/internal/phone/gpt-live-round2/*` exist only when the application is a protected Vercel Preview and a server-to-server request presents the existing Preview automation credential in the dedicated internal header. Main, Production, PSTN dialing, Phone approvals, Gmail actions, and automatic durable-memory writes are outside this prototype.

## Voice shortlist

No sample audio is generated by this change. The later owner listening comparison should start with `marin` (current default), `willow` (natural feminine Irish influence), and `gleam` (natural feminine North American influence). OpenAI recommends testing multilingual pronunciation for the intended language mix; the application must keep the selected voice fixed for each session.
